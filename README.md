# MTT 锦标赛训练营

一个用来学习德州扑克的互动网页，有两门课，在课程页顶部切换，进度分开记录：

- **锦标赛（MTT）**：8 周、26 节课，从规则和位置学到短码推弃、偷盲反推、翻牌圈判断、ICM 和决赛桌。
- **现金局**：6 周、22 节课，以线上最常见的 6 人桌、100 BB 为主，从资金管理学到翻牌前范围、翻牌后打法和读人。

每节课先复习前面的内容，再读要点、去练习场完成任务，最后做随堂测验，全部达标后自动解锁下一课。

页面只有一个 `index.html`，不需要安装和构建。`server.mjs` 是可选的本地服务，只在接入 AI 时可能用到。`miniprogram/` 是同样内容的微信小程序版本，见下面的“微信小程序”。

## 怎么用

- **本地**：双击 `index.html`，用浏览器打开。
- **在线**：在仓库的 Settings → Pages 里，选择从 `main` 分支的根目录发布，就能得到一个网址。
- **接入 AI 时**：如果浏览器直连 AI 接口被跨域限制拦住，就在项目文件夹里运行下面的命令（需要 Node.js 18 或更高版本），然后打开 http://127.0.0.1:8787 。

  ```bash
  node server.mjs
  ```

## 内容

**锦标赛课程**

| 阶段 | 周 | 内容 |
|---|---|---|
| 一 · 打基础 | 1–2 | 比赛规则、位置、大盲数与 M 值、底池赔率、补牌、起手牌，阶段测验 |
| 二 · 短码推弃 | 3–4 | 只推或弃的原因、后位与前位推弃、极短码、决策与结果，阶段测验 |
| 三 · 中码与翻牌后 | 5–6 | 开池加注、后位偷盲、3bet 全下反击、翻牌圈牌面、持续下注、复盘，阶段测验 |
| 四 · ICM 与决赛桌 | 7–8 | 筹码不等于钱、泡沫因子、大中短码打法、钱圈、决赛桌，毕业测验 |

**现金局课程**

| 阶段 | 周 | 内容 |
|---|---|---|
| 一 · 现金局基础 | 1 | 和锦标赛的区别、资金管理与方差、6 人桌位置，阶段测验 |
| 二 · 翻牌前 | 2–3 | 开池范围、隔离平跟、面对开池、大盲防守、面对 3bet、挤压与多人底池，阶段测验 |
| 三 · 翻牌后 | 4–5 | 持续下注与牌面、下注尺寸、隐含赔率与听牌、SPR、价值下注与诈唬比例、最少防守频率（MDF），阶段测验 |
| 四 · 读人与长期 | 6 | 针对不同对手调整、VPIP / PFR / bb/100、情绪控制和复盘，毕业测验 |

**测验**：两门课的题库共 174 道选择题（锦标赛 94 道，现金局 80 道），每道都附解释。

- **复习**：每课开头，从前面的课程里随机抽 4 题，至少答对 3 题。
- **随堂测验**：每课结尾 4 到 5 题，正确率至少 80%。
- **阶段测验**：从本阶段抽 10 题；毕业测验从全课程抽 15 题。两者都要求正确率至少 80%，还要完成对应的练习任务。

**模拟赛**：和 8 个不同风格的电脑对手（紧弱、标准、松凶、跟注站）同桌，打完整的德州扑克，四条街都可以弃牌、过牌、跟注、加注或全下，有边池结算。

- **完整锦标赛**：可选 18、45、90 或 180 人参赛，起始 100 BB 或 50 BB，盲注速度三档。从第一级盲注一直打到出局或夺冠：盲注定时上涨，其他桌不断有人出局，空位会有玩家移过来；会提示泡沫期、钱圈、决赛桌和单挑，显示平均筹码、你的大致排名和各名次奖金。每打完一手自动存档，可以随时离开，下次接着打。
- **专项训练**：短码推弃、中码偷盲与反推、泡沫期、决赛桌、早期深筹码，共 5 个场景。每个场景打满固定手数，中途出局会自动重新坐下继续练。
- **现金局 6 人桌**：盲注固定 0.5/1 BB，没有前注，买入 100 BB。可选 50、100、200 手或不限手数，对手可选均衡、鱼多或常客多，低于 100 BB 可以自动补满。翻牌前按 6 人桌的开池、隔离、3bet、大盲防守和面对 3bet 的范围判断。统计盈亏、bb/100、入池率（VPIP）和翻牌前加注率（PFR），打完显示盈亏曲线。每打完一手自动存档，可以离开后回到牌桌。

- 每次轮到你行动，系统都会判断你的选择，并说明理由：翻牌前看课程里的范围表；面对全下时，用蒙特卡洛模拟估算胜率，再和底池赔率比较；泡沫期加上风险溢价，决赛桌按真实 ICM 计算。
- 行动前可以点“提示”看推荐。
- 打完会显示总结：各类决策的正确率，以及每个错误的回顾。

**AI（可选）**：在“模拟赛 → AI 设置”里填写 OpenAI 兼容的接口，比如 DeepSeek、通义千问、Kimi、智谱、硅基流动、豆包，或本地的 Ollama。接入后可以：

- 选错时让 AI 详细讲解；
- 行动前看了“提示”后，让 AI 解释为什么这样推荐；
- 在练习场答完一题后，让 AI 讲解这道题；
- 让 AI 按各自的风格扮演对手；
- 比赛结束后让 AI 复盘整场。

AI 讲解、提示、练习讲解和复盘下面都有追问框，可以接着提问（也可以点“为什么不是别的选择？”这类常用问题），AI 会结合这手牌和前面的对话回答。

API Key 只保存在你自己的浏览器里，只会发送到你填写的接口地址，或本机的 `server.mjs`。`server.mjs` 只转发到常见服务商的地址；需要其他地址时，用 `MTT_ALLOW_HOSTS=域名 node server.mjs` 启动。

**练习场**：按当前课程显示对应的练习。

- 锦标赛：位置、筹码分区、手牌比较、底池赔率、推弃、开池、反推、翻牌牌面、ICM 跟注，共 9 种。
- 现金局：6 人桌位置、6 人桌开池、隔离平跟、面对开池、大盲防守、面对 3bet、翻牌牌面、底池赔率、隐含赔率、SPR、MDF 与诈唬比例、河牌价值与诈唬，共 12 种。

答完每题都会给出解释，涉及范围的题目还会显示 13×13 手牌范围图（现金局的范围图会分开标出加注和跟注的牌）。

**其他工具**

- **赛程地图**：比赛的五个阶段，平均筹码深度曲线，以及大盲数和 M 值计算器。
- **ICM 实验室**：拖动筹码，比较筹码占比和奖金权益，并计算泡沫因子。
- **生存挑战**：模拟一场 100 人的比赛，从 15 个大盲打到决赛桌。真实发牌、比牌，并把决策正确率和比赛结果分开统计。

## 微信小程序

`miniprogram/` 是给自己用的微信小程序版本，有课程、测验、练习场、模拟赛（完整锦标赛、专项训练、现金局 6 人桌）、赛程地图、ICM 实验室、生存挑战和 AI 追问，内容和判断规则与网页版相同。

**在手机上用**

1. 在[微信公众平台](https://mp.weixin.qq.com/)注册一个个人主体的小程序，在“开发管理 → 开发设置”里找到 AppID。
2. 用[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)导入 `miniprogram` 文件夹，把 AppID 换成你自己的（仓库里填的是游客 AppID `touristappid`，只能在电脑上的模拟器里运行）。
3. 点“预览”用微信扫码，或者“上传”后在公众平台把这个版本设为体验版。不需要提交审核，也不对外发布。德州扑克内容个人主体一般过不了审核，所以只建议当体验版自己用。
4. 要用 AI：在公众平台“开发管理 → 开发设置 → 服务器域名”里，把接口域名（比如 `https://api.deepseek.com`）加到 request 合法域名。只是自己用的话，也可以在手机上打开小程序的“开发调试”跳过这个检查。

小程序的进度存在手机的微信里，和网页版分开记录。

**和网页版保持同步**

课程、题库、范围表、练习题、牌局引擎、电脑对手和教练规则都写在 `index.html` 里。`miniprogram/core/engine.js` 是从它自动生成的，不要手改。改完 `index.html` 后运行：

```bash
npm install
```

```bash
npm run build:mp
```

脚本会抽出网页里的共享代码，去掉只负责画网页的函数；共享代码调用这些函数时，转给小程序自己的页面处理。小程序的界面在 `miniprogram/pages/` 里，新增网页界面功能时要在这里另外实现。

## 学习进度

进度保存在浏览器的 localStorage 里，换浏览器或清除网站数据后会丢失。

## 说明

推弃、开池和反推范围是按手牌强度排序、参照常见纳什推弃比例近似生成的教学版本，不是精确的解算结果。现金局的 6 人桌范围参考常见的 100 BB 打法简化而来：3bet 和 4bet 以价值牌为主，只把 A5s 到 A2s 当作可以接受的诈唬，实际的平衡打法会混合更多诈唬和频率。翻牌圈牌面判断用的是简化规则。模拟赛里翻牌后的判断，是按对手可能的范围估算胜率；对手下注后，只按他范围里较强的那部分来算。这也是简化估算。这些内容适合用来建立直觉，实战中还要考虑对手倾向、筹码分布和 ICM。
